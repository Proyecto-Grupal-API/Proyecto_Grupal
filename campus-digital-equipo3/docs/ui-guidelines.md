# UI — Campus Digital

La interfaz de Equipo 3 conserva la estructura visual observada en la referencia:

- Barra lateral azul marino `#10285D`
- Azul principal `#23479B`
- Fondo general `#F4F7FC`
- Tarjetas blancas con bordes suaves
- Rojo de acciones críticas `#F34A45`
- Amarillo para indicadores destacados `#F5C62E`
- Verde para estados activos `#37B978`
- Navegación superior mediante píldoras
- Espaciado y tarjetas tipo dashboard
- Tienda integrada en el menú principal

La página `/tienda` es el punto de entrada del Equipo 3.
