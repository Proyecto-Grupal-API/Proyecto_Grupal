# Validación y límites de la entrega

- Base incremental: rama financiera e8645bb; comparación por hashes de contenido normalizado antes de aplicar.
- Interfaz existente reutilizada y pantalla nueva de asignaciones; funciones separadas entre identidad, autorización contextual, administración financiera y transporte web.
- Pruebas nuevas: matriz de 11 actores; roles embebidos sin autoridad; revocación/vencimiento/permisos desactivados; aislamiento entre contextos; auditor de solo lectura; membresía de negocio; idempotencia; fallo de auditoría sin emisión parcial; transacción de asignación y membresía; factor confirmado; desactivación sin pérdida; origen inmutable; consulta transversal con permiso explícito.
- Verify ejecuta pruebas nuevas y regresiones de toda la carpeta financiera, incluyendo compras, devoluciones, límites y transferencias.
- PHP y servicios de datos no están disponibles en el entorno de elaboración: los resultados de ejecución permanecen pendientes de tu verificación. No se incluyen resultados inventados.
- Autorización se vuelve a leer al atender la petición y antes de escrituras críticas. MongoDB y SQL Server son sistemas distintos: no se promete una transacción distribuida entre revocación de roles y escritura financiera.
- La gestión de asignaciones exige replica set MongoDB. No se modifica tu configuración de conexión, usuarios existentes ni contraseña.
- La integración oficial de catálogos de asociación, consejo y servicio sigue pendiente del contrato. Los IDs son una declaración administrativa explícita para desarrollo, no una validación contra un catálogo inexistente.
- No se añade un endpoint público de asignación ni se altera el bloqueo de /roles/assign. Bootstrap es local y explícito; interfaz usa permisos persistidos, no roles antiguos embebidos.
- La matriz queda cerrada en FinancialRoleCatalog v2; los administradores configuran quién tiene cada rol, su contexto y vigencia. Modificar la matriz general requiere cambiar esa política/adaptador de identidad, no escribirla desde el cliente.
